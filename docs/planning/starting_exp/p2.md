# Part 2: Main Python Pipeline Script (`src/extractor.py`)

## Subtasks
1. **Initialize Script & Client:** Create `src/extractor.py` and set up the Azure OpenAI client using `ManagedIdentityCredential` (replicating the `model_call_example`).
2. **File Loading Logic:** Implement a function to read the raw Markdown file from the handbook directory.
3. **Prompt Construction:** Implement a function to load the prompt template from `docs/file_formats/policy_extraction_prompt.md` and inject the markdown content.
4. **API Integration:** Construct the API call to `gpt-5-nano` sending the formatted prompt.
5. **Output Handling:** Implement a parser to extract the JSON from the model's response and save it to an output file.
