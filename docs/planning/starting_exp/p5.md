# Part 5: LTL Rule Extraction

## Subtasks
1. **Pipeline Extension:** Extend `src/extractor.py` (or create `src/rule_extractor.py`) to accept the structured policy JSON generated in Part 4.
2. **Prompt Loading:** Load the `docs/file_formats/rule_extraction_prompt.md` template.
3. **LLM Query:** Feed the structured policy into the model to extract atomic predicates and Linear Temporal Logic (LTL) rules.
4. **Validation:** Save the output and validate it against `docs/file_formats/rule_extraction_format.json`.
