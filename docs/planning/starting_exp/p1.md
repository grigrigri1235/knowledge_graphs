# Part 1: Environment Setup (Conda)

## Subtasks
1. **Create `environment.yml`:** Define the Conda environment configuration file specifying `python` and the necessary dependencies (`openai`, `azure-identity`).
2. **Build the Environment:** Execute `conda env create -f environment.yml` to create the isolated environment.
3. **Verification:** Activate the environment and run a quick test (or `conda list`) to ensure the packages are installed correctly.
