# Part 3: Single Document Extraction POC

## Subtasks
1. **Target Inspection & Preprocessing:** Inspect `handbook/content/handbook/legal/record-retention-policy.md`, verify length/token metrics, and determine if YAML frontmatter needs stripping.
2. **Dry-Run Prompt Preview:** Add a dry-run flag to `src/extractor.py` to assemble the prompt and write it to disk (`output/prompt_preview.txt`) for human review without calling the model.
3. **Auth & Connectivity Ping:** Run a minimal connectivity test (1-token query) to verify Azure OpenAI credentials and endpoint health prior to sending the full document.
4. **Extraction Execution:** Execute the full extraction script against the preprocessed target document.
5. **Output & Monitoring:** Monitor API latency and errors, verify output JSON creation, and capture logs.
