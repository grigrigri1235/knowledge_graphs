# Part 7: Verifiability Refinement (VR)

## Objective
Implement and execute the Verifiability Refinement (VR) stage from Section 3.2.3 of the ShieldAgent paper using `docs/file_formats/vr_prompt.md` and `docs/file_formats/rule_optimization_format.json`.

## Subtasks
1. **VR Script Development:** Create `src/refiner_vr.py` using Azure OpenAI (`gpt-5-nano`) to evaluate rules from `output/wiki_extracted_ltl_rules.json`, checking predicates for verifiability, concreteness, accuracy, and atomicity.
2. **Dry-Run Prompt Preview:** Verify prompt assembly and preview via `--dry-run` flag saved to `output/wiki_vr_prompt_preview.txt`.
3. **Execution & Refinement:** Run `src/refiner_vr.py` on the extracted retail LTL rules to produce `output/wiki_vr_refined_rules.json`.
4. **Validation & Review:** Validate that outputs adhere to `docs/file_formats/rule_optimization_format.json` and generate `output/wiki_vr_review.md`.
