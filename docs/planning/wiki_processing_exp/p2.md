# Part 2: Policy Output Schema Validation

## Subtasks
1. **Load Output:** Read the JSON file generated in Part 1 (`output/wiki_extracted_policies.json`).
2. **Schema Comparison:** Compare the structure of the JSON output against `docs/file_formats/policy_extraction_format.json`.
3. **Field Verification:** Validate all required fields (`definition`, `scope`, `policy_description`, `reference`) across all policy objects for correct types and non-empty values.
4. **Validation Log & Review:** Write the policy schema validation report to `output/wiki_policy_review.md`.
