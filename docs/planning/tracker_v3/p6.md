## Objective
Implement every fact part whose source is the database, the event log or the call's arguments: the 31 code-type
facts, plus the database and event parts of the mixed airline facts (cancelled flight, 24 hours, membership,
insurance, cabin, certificate amounts).

## Steps
1. Write the expressions of p5 for these parts.
2. Tests `tests/test_v3_code_facts.py`: tiny conversations built with real tool outputs (`state.run_tool`). For each
   fact: true, false, a nonexistent id, a missing argument, and each fixed reading of p5.
3. **Agreement run:** on every saved write attempt of the development data, compare each database fact with the
   τ-bench tool label of p3. Report `output/eval_v3/p6_tool_agreement.md`.
4. **The eval v2 harm set:** the 420 blocked checks where the judge said "unknown" and v2 said "false", mostly
   because the gift card was never shown (37 strong + 383 weak, `good_success_stage_a.md` lines 209-212). For each: the new value of the fact, and τ-bench's tool label for
   it. The 428 in `output/eval_v2/stage_a_runs.md` line 319 counts a slightly different set; both are recomputed, and
   the difference is written down. Note: 356 of the 420 are also blocked by another rule (mostly a reminder), so they
   stay blocked whatever the gift-card value. That is why the pass mark is on the fact, not on the decision.

## New files
The expressions in `facts_v3_<domain>.json` (p5), `tests/test_v3_code_facts.py`,
`output/eval_v3/p6_tool_agreement.md`.

## How we know it is right, without a person
- **τ-bench's own tool:** 0 disagreements on the facts it decides. Each disagreement is a bug, fixed and logged in
  the pre-registration change log.
- **Replay:** the state gives the saved tool outputs exactly. Target: 0 mismatches.
- **The event log:** an event fact is true exactly when the saved conversation has that worked tool call (checked on
  all development conversations; the hold-out once in p12).
- **The 420 set:** the fact's new value equals τ-bench's tool label in 100 % of the checks where the tool decides
  it.
