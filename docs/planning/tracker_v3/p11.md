## Objective
Re-decide every saved check of the development data with v3, for $0, and count what changes and whether it is
right. Until p12, the meaning facts use the judge's saved answers as a stand-in.

## What runs
| name | switches | what it shows |
|---|---|---|
| frozen, v2 | the saved guards | where we start |
| **v3** | facts=v3, meaning=saved_judge, messages=frozen | the new facts: what decisions change |
| v3, other readings | as v3, with each reading choice flipped (Q4, Q6, Q7) | what each choice moves |
| messages | rule and simple vs frozen, on the same blocks | the message change alone |

## Steps
1. **First divergence:** for each conversation, the first check (tries 1-3) where v3 decides differently from the
   saved guard. Checks after it are descriptive only, because the conversation would have gone differently.
2. **Counts:**
   - blocks removed and added, per data set, agent, rule and fact;
   - messages changed, by class;
   - **how much an LLM still decides:** the share of values behind blocks set by the judge stand-in, against code,
     for frozen, v2 and v3.
3. **Labels for each changed decision:**
   - τ-bench's tool check (p3);
   - its expected actions from the task files: exact, near (same tool and object, other arguments), or unwanted;
   - "ran later anyway";
   - task success.

   Fixed classes:
   - **good:** a block removed on an exact wanted call the tool accepts;
   - **bad:** a new allow that the tool refuses on a check mapped to a v3 fact (p3);
   - **suspect:** a block added on an exact wanted call;
   - **reported, split by the fact that changed:** a new allow on an unwanted call. With the rule met, this can be the
     agent's own mistake (a wrong item), which no rule covers;
   - **undecided:** near matches, and confirmation facts.
4. **The 420 harm set (p6):** the gift-card fact (or the other changed fact) now equals τ-bench's tool label. The
   decisions there are reported: 356 of the 420 stay blocked by another rule.
5. **The audit (p4) again**, on v3: what changed in each bucket.
6. **The ceiling table again** (overview), for v3.
7. **"Rule broken" counts** from v3's own facts and rules, for both arms. Reported only, because v3 enforces these
   same rules.
8. **Split by length:** all counts, in the length bins of p1.
9. **Statistics:** a bootstrap by task (10,000 resamples, fixed seed); 3/n for zero-count pass marks.
10. **Report** `output/eval_v3/p11_offline.md`, with figures (`docs/reports/figures/v3_offline_*.png`): changed
    decisions by length bin; the share decided by an LLM; the audit buckets. Then **STOP**.
