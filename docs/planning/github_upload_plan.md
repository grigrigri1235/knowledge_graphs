# GitHub Upload Plan

## Objective
Upload all project files in `/home/azureuser/code_projects` to the new GitHub repository: `https://github.com/grigrigri1235/knowledge_graphs.git`.

## Micro-Steps for Sequential Execution
1. **Part 1:** Initialize the git repository in `/home/azureuser/code_projects` and output the result to `git_init.log`.
2. **Part 2:** Stage all files for commit using `git add .` and output the result to `git_add.log`.
3. **Part 3:** Commit the files with the message "Initial commit" and output the result to `git_commit.log`.
4. **Part 4:** Set the main branch to `main` and add the remote origin `https://github.com/grigrigri1235/knowledge_graphs.git`, outputting results to `git_remote.log`.
5. **Part 5:** User manually runs `git push -u origin main` in their terminal to securely handle authentication.
