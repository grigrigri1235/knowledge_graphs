# Part 7: Manual Check of the Disagreements

## Objective
Find out who is right when the tracker and the judge disagree.

## What counts as correct
- For a predicate whose lookup uses *fact*: the value in the database copy at that step.
- For a predicate whose lookup uses *shown*: what the conversation had shown before the step.
- In both cases, the predicate's description decides. If the description is unclear, the reviewer marks "predicate
  unclear".

## Subtasks
1. **Sample** (fixed seed):
   - all disagreements on blocked steps;
   - a random sample of the other disagreements, up to about 150 items in total;
   - 50 agreements as a control.
2. **Write the review sheet** `output/p7_review_sheet.md`. For each item:
   - the predicate description;
   - the part of the conversation that matters;
   - the judge's value and evidence;
   - the tracker value, whether the lookup uses *fact* or *shown*, and the object or event it used;
   - for a database object: its value in the database copy, and whether (and how) the conversation had shown it.

   The reviewer marks one of: tracker right / judge right / both wrong / predicate unclear.
3. **Review:** done by a person (you or your partner), not by me.
4. **Gold check (scoring only),** after the review:
   - copy the gold predicate code (`~/ShieldAgent/agent/predicates/`) to `from_shieldagent/gold/`, and add it to
     `PROVENANCE.md`;
   - for predicates that mean the same as a gold check, compare the three values (gold, tracker, judge);
   - a test (`tests/test_no_gold_import.py`) checks that nothing in `state_tracker/` imports the gold code.
5. **Results** in `output/p7_review_results.md`: accuracy of the tracker and of the judge on the checked items, per
   type, and the main reasons for errors, with examples.

## Deliverables
- `output/p7_review_sheet.md` (filled in by the reviewer) and `output/p7_review_results.md`.
- `from_shieldagent/gold/` and `tests/test_no_gold_import.py`.

## Done when
- Every sampled item is reviewed, and the results table is written.
