# Part 6: Replay: Tracker Values vs Judge Values

## Objective
For every saved guarded step, compute the lookup values and compare them with the judge's values.

## Subtasks
1. **Write `state_tracker/replay.py`.** For each Part 2 record, and each code-type predicate in the step's rules:
   1. build the state;
   2. run the lookup;
   3. store the tracker value next to the judge's value.
2. **Save one line per step and predicate** to `output/p6_values.jsonl`, with:
   - run, domain, task, trial and step;
   - predicate and type;
   - the judge's value and evidence;
   - the tracker value, and the object or event it used.
3. **Agreement table** `output/p6_agreement.md`, per predicate and per type:
   - number of values;
   - both agree;
   - judge true, tracker false;
   - judge false, tracker true;
   - cases where either one is unknown.

   Steps that were blocked are shown separately.
4. **Save the disagreements** to `output/p6_disagreements.jsonl`.

## Deliverables
- `state_tracker/replay.py`.
- `output/p6_values.jsonl`, `output/p6_agreement.md` and `output/p6_disagreements.jsonl`.

## Done when
- Every code-type value has a tracker value, or is unknown with a reason.
