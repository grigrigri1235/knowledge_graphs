Rule form. Write every policy requirement as a linear temporal logic formula over finite traces (LTLf) in "logic". The trace has one position per agent action; an action is an atom that is true at the position where the agent takes that action. Allowed operators: NOT, AND, OR, IMPLIES, ALWAYS, EVENTUALLY, NEXT, UNTIL, parentheses. Atoms are actions and condition predicates. Prohibitions, obligations and permissions may each be written as separate rules. Every rule must mention at least one action. Sentences that only describe facts produce no rule.
